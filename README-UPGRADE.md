# Axis DPO — Secure Multi-Company Upgrade

This version replaces the prototype login and split SQLite backends with a unified authenticated API and a shared PostgreSQL database.

## What changed
- Axis Solutions logo added to the sign-in and admin interfaces.
- Real email/password authentication using Argon2 password hashes and signed JWT sessions.
- Admin creates a company and its DPO account (company name, DPO name, DPO email, temporary password).
- Every client DPO is linked to one company. The API derives the company ID from the authenticated account; client-submitted company IDs are not trusted.
- Client record endpoints are tenant-scoped. DPOs cannot request another company's records.
- Admin can list companies and suspend/restore DPO access.
- Audit events record account provisioning, password changes and client uploads.
- One API service and one shared Render PostgreSQL database. Old client_backend.py and admin_backend.py are retained only as historical files and are NOT deployed.

## Render deployment

**Important:** this is a database architecture change. Do not deploy this as an in-place replacement against the old SQLite services and expect existing demo records to migrate automatically. Take an export/backup of any real records first. The earlier sample company rows were demo data, not verified customer records.

1. Commit the entire contents of this folder to the root of the GitHub repository (including `.python-version`, `render.yaml`, `api.py`, `requirements.txt`, and `public/`).
2. In Render, use **New + → Blueprint** and select the repository. The Blueprint creates:
   - `axis-dpo-postgres` (managed PostgreSQL)
   - `axis-dpo-api` (unified FastAPI service)
   - `axis-dpo-frontend` (static website)
3. In the Blueprint prompts, set:
   - `AXIS_ADMIN_EMAIL`: the Axis administrator's real work email.
   - `AXIS_ADMIN_PASSWORD`: a strong unique initial password (at least 12 characters).
   - `FRONTEND_ORIGINS`: the exact static frontend URL, e.g. `https://axis-dpo-frontend.onrender.com` (no trailing slash).
4. The `JWT_SECRET` is generated by Render. `DATABASE_URL` is connected to the managed PostgreSQL database automatically.
5. Confirm the frontend URL and API URL are correct. If Render assigns a different API hostname, update `public/config.js` to that exact API origin and redeploy the static site.
6. Wait for `/health` on the API to return `{"status":"ok",...}`.
7. Sign in with the admin email/password configured above. From Administration, add each company and its DPO. Use a unique temporary password of at least 12 characters and share it securely. The DPO should change it after their first sign-in.

## Important limitations / production checklist
- The DPO temporary password is manually handed to the user; this package does not send invitation emails. Connect an approved transactional email provider before automating invitations or password resets.
- Uploaded documents are currently hashed and their metadata is stored; the raw file is not retained. Add private object storage (e.g. S3-compatible storage) and malware scanning before treating the platform as a document vault.
- The compliance score and Kaspersky text scanning are indicative workflow features, not a legal determination or a full XDR integration. Validate legal rules and reporting obligations with qualified counsel.
- Configure backups, monitoring, rate limiting, MFA, password reset, session revocation and a security review before production use.
- The new PostgreSQL database starts empty. Existing SQLite data is not migrated by this package.
- Set a paid persistent PostgreSQL plan and review ongoing hosting costs before onboarding clients.

## Local development
```bash
python -m venv .venv
# activate the environment
pip install -r requirements.txt
set AXIS_ADMIN_EMAIL=admin@example.com
set AXIS_ADMIN_PASSWORD=Use-a-unique-password-12
uvicorn api:app --reload --port 8000
```
Open `public/index.html` through a local static server (for example `python -m http.server 5500 --directory public`). The local API uses `axis_local.db` SQLite unless `DATABASE_URL` is set.
